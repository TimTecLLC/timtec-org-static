# =============================================================================
# timtec.net → www.timtec.org  (Apache 2.4)
# =============================================================================
#
# INSTALL ON THE timtec.net HOST ONLY.
# Copy this file to the timtec.net web root as `.htaccess`, or merge the
# RewriteRule block into the existing Apache vhost.
#
# Do NOT deploy this file on GitHub Pages. Pages does not run Apache rewrite
# rules from this repository. The corrected destination map is documented in
# docs/timtec-net-to-org-redirects.md
