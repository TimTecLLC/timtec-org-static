Privacy

How this test site treats information

TimTec states that it stores customer data on a secured SSD that is never connected to the internet. Quotes, orders, and files you send by email go to TimTec mailboxes (timtec@timtec.org, orders@timtec.org, ledger@timtec.org), not into a database on this GitHub Pages host.

This repository is a static marketing rebuild. The inquiry form only opens a mailto: draft in your email client. There is no Formspree or application server in this repo. GitHub, your browser, and any fonts loaded from Google Fonts may process standard technical logs.

The live www.timtec.org site (IONOS) may use its own cookies, analytics, maps, and translation tools. This test site does not embed those third-party trackers.

External catalog tools (structure search, ID/SMILES, SDS, CoA, legacy login, TT-BOT) are separate systems. Review those hosts’ practices before uploading structures.

Questions: timtec@timtec.org.
